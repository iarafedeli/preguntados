Sistema Preguntados es un juego de trivia multijugador inspirado en el clásico "Preguntados". Puedes jugarlo en el mismo navegador, con dos jugadores por turnos en un solo dispositivo, o entre dos dispositivos independientes mediante un código de sala.

El sistema combina una SPA (Single Page Application) en React, que se ejecuta en el navegador, con un microservicio REST en FastAPI. El backend suministra preguntas categorizadas desde una base de datos relacional PostgreSQL.

## Estado del proyecto

El equipo cataloga el proyecto como **Release Candidate**: un prototipo funcional avanzado, completo para el juego multijugador local y online. Según el informe técnico, el proyecto incluye:

- Pantallas implementadas para todas las fases del juego: ruleta, preguntas, coronas, duelos y modo online.
- Pruebas unitarias automatizadas sobre la capa de transporte.
- Un respaldo automático con preguntas locales y traducción dinámica cuando el backend no está disponible.
